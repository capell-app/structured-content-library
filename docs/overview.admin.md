## What it does

Structured Content Library is the shared place for reusable, structured content. Create items here when another Capell feature or theme needs consistent case studies, testimonials, team members, services, FAQs, resources, partners, locations, or logos.

## Where to manage it

Go to **Content → Structured Content Items**. The list shows each item's title, type, status, publication date, and position. Search by title; filter by type or status; and drag items into their intended order. Deleted items remain available through the trash filter until they are permanently deleted.

## Create an item

1. Select **Create structured content item**.
2. Choose its **type** and **status**. New items default to **Draft**.
3. Add the required title, then complete the optional slug, summary, and content fields.
4. Use **Published at** when the item should be published at a particular time, and set **Sort order** when its consuming feature uses the shared ordering.
5. Complete the type-specific fields that appear below the main content. For example, testimonials have quote and attribution fields, FAQs have a question and answer, and locations have contact and address fields.
6. Save the item.

## Publishing and reuse

- Only items with the **Published** status are available to public structured-content output; a future **Published at** date keeps an item out of that output until the date arrives.
- Change an existing item back to **Draft** or **Archived** to remove it from public structured-content output without deleting it.
- The package does not place items on a page by itself. Configure the theme, widget, or feature that consumes the chosen content type to display them.

## Good to know

- Slugs are unique for the selected type and site. Leave the slug blank to derive it from the title.
- Use the row or edit-page deletion controls to move an item to the trash. Restore it from the trash filter when needed; permanent deletion is available from the bulk actions or the edit page.
